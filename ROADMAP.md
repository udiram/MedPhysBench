# Roadmap

The current public suite proves the evaluation and publication loop. It does not yet justify a
claim of medical-physics-wide model competence.

## Release gates

- [x] Versioned public task, runtime, run, result, and release contracts
- [x] Sealed candidate view and deterministic outcome/safety grading
- [x] Complete-run integrity audit and output-derived public scoring
- [x] Public evidence package, leaderboard, CI, and reproducibility documentation
- [ ] Independent expert review board with published conflict and adjudication policy
- [ ] At least 100 dual-reviewed tasks with prespecified domain/risk quotas
- [ ] Resettable file, DICOM, database, and virtual-instrument task environments
- [ ] Private rotating holdout with contamination controls and audited access
- [ ] Repeated multi-seed evaluation and hierarchical uncertainty estimates
- [ ] External replication by an unaffiliated medical-physics group

## Contribution priorities

1. Authentic artifact tasks with redistributable synthetic fixtures.
2. Imaging, brachytherapy, nuclear medicine, shielding, and informatics depth.
3. Failure-mode tasks where abstention or escalation is the only safe outcome.
4. Additional provider adapters that preserve the common-harness contract.
5. Independent task solvability, leakage, and grading audits.
