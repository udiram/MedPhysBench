# Security policy

## Supported versions

Only the latest tagged MedPhysBench release receives security fixes.

## Reporting

Do not open a public issue for:

- access to sealed task labels or grader configuration;
- PHI or other sensitive data exposure;
- credential leakage;
- sandbox escape or unauthorized tool access;
- an integrity flaw that could silently alter public scores.

Report privately through GitHub Security Advisories for this repository. Include reproduction steps,
affected versions, likely impact, and whether public results may need retraction.

## Benchmark-integrity incidents

The maintainers may freeze submissions, mark a release compromised, retract affected scores, rotate
holdouts, and publish a post-incident report. Safety and integrity corrections do not preserve a
model's previous rank.
